Core project for all my in-house projects. Written with a monolithic structure for easy expansion and modification, and less overhead.

## To build
1. Download node.js from https://nodejs.org/en/download/
2. Install node.js
3. Open terminal
4. Navigate the the src folder
5. Run the command `npm install`
6. Run the command `npm run build`
